# Liquid Glass iOS App 🪟✨

Приложение на SwiftUI с дизайном в стиле **Liquid Glass (жидкое стекло / glassmorphism)**:
- Плавающие анимированные градиентные капли (жидкость).
- Эффект матового стекла (`.ultraThinMaterial`), блики по краям и неоновые тени.
- Кнопки взаимодействия («Увеличить», «Сброс», «Волна») и интерактивный счётчик.

---

## 🚀 Как получить `.ipa` файл через GitHub (без Mac):

1. **Создайте новый репозиторий на GitHub** (назовите, например, `ios-liquid-glass`).
2. **Загрузите все файлы из этой папки** в корень вашего репозитория:
   - `LiquidGlassApp.swift`
   - `ContentView.swift`
   - `Info.plist`
   - `project.yml`
   - Папку `.github/workflows/build.yml`
   
   *(Если используете Git в терминале):*
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/<ваш-репозиторий>.git
   git push -u origin main
   ```

3. **Сборка начнется автоматически**:
   - Перейдите во вкладку **Actions** в репозитории на GitHub.
   - Вы увидите запущенный воркфлоу **Build iOS IPA**. GitHub бесплатно выделит виртуальную машину с macOS и соберет проект.
   - Сборка занимает около 2-3 минут.

4. **Скачивание `.ipa`**:
   - Когда появится зеленая галочка, кликните по названию сборки.
   - Внизу в блоке **Artifacts** нажмите на **LiquidGlass-IPA** и скачайте архив с файлом `LiquidGlass.ipa`.

## 📱 Как установить `.ipa` на iPhone с Windows:

Так как сборка без платного сертификата Apple Developer, установите приложение через любой sideloading-инструмент (они подпишут IPA вашим бесплатным Apple ID):

1. **Sideloadly** (самый простой вариант для Windows):
   - Скачайте Sideloadly (sideloadly.io) и iTunes/iCloud (не из MS Store).
   - Подключите iPhone по проводу к ПК.
   - Перетащите скачанный `LiquidGlass.ipa` в окно Sideloadly, введите ваш Apple ID и нажмите **Start**.
2. **AltStore**:
   - Установите AltServer на Windows и установите приложение AltStore на телефон, затем откройте в нем `.ipa`.
3. **На iPhone**:
   - Зайдите в *Настройки -> Основные -> VPN и управление устройством*.
   - Нажмите «Доверять» вашему профилю разработчика.
   - Если у вас iOS 16+, включите *Режим разработчика* (*Настройки -> Конфиденциальность и безопасность -> Режим разработчика*).
